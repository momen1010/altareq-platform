# ال طارق · Al Tareq

منصة إلكترونية لتعليم اللغة العربية: نحو وصرف وبلاغة وإملاء وخط عربي وقراءة وأدب، ودورات للناطقين بغير العربية. المتعلم يتصفح كتالوجًا ثنائي اللغة (عربي/إنجليزي مع دعم RTL كامل)، ويشتري الدورات عبر Paymob، ويشاهد الدروس، ويحتفظ بملاحظاته، ويجتاز اختبارًا في نهاية كل دورة، ويحصل على شهادة يمكن لأي شخص التحقق منها. والمدرس يبني دوراته من استوديو خاص ويستلم أرباحه، والأدمن يدير كل شيء من لوحة واحدة.

المشروع مبني على منصة [منهل (Manhal)](https://github.com/AbanoubRashad/manhal) مفتوحة المصدر بترخيص MIT، مع إعادة تسمية كاملة ومحتوى عربي جديد لتعليم اللغة العربية.

## التشغيل محليًا

يتطلب Node.js 22.13 أو أحدث. لا توجد أي حزم للتثبيت — صفر اعتماديات (`node:http` و`node:sqlite` و`node:crypto`).

```bash
npm start         # http://localhost:3000 — ينشئ data/altareq.db ويزرع بيانات تجريبية
npm run dev       # نفس الشيء مع إعادة التشغيل عند تعديل الملفات
npm test          # 104 اختبارات عبر node:test
npm run backup    # نسخة احتياطية من قاعدة البيانات في data/backups/
```

رسائل البريد تُطبع في السجل أثناء التطوير. افتح **http://localhost:3000/dev/mail** لقراءتها واستخدام روابط التفعيل وإعادة التعيين.

### حسابات تجريبية

| الدور | البريد | كلمة المرور |
|---|---|---|
| متعلم | `learner@altareq.test` | `altareq-learn` |
| مدرس (طارق) | `tarek@altareq.test` | `altareq-teach` |
| أدمن | `admin@altareq.test` | `altareq-admin` |

باقي المدرسين التجريبيين يستخدمون `<الاسم الأول>@altareq.test` بكلمة مرور `altareq-teach`. الكوبونات: `ALTAREQ20` (خصم 20%) و`LAUNCH50` (خصم 50%، 100 استخدام). البيانات التجريبية تُزرع فقط في قاعدة بيانات فارغة، ولا تُزرع في الإنتاج إلا بضبط `SEED_DEMO=true`.

## الإعدادات

انسخ `.env.example` إلى `.env`. أهم المتغيرات:

| المتغير | الافتراضي | الغرض |
|---|---|---|
| `PORT` | `3000` | منفذ HTTP |
| `BASE_URL` | `http://localhost:3000` | الرابط العام لروابط البريد ووسوم Open Graph وخريطة الموقع وردود Paymob. يجب أن يكون `https://` في الإنتاج |
| `NODE_ENV` | `development` | `production` يفعّل الكوكيز الآمنة ويرفض الإعدادات غير الآمنة |
| `DATABASE_PATH` | `data/altareq.db` | ملف SQLite (وضع WAL) |
| `EMAIL_PROVIDER` | `console` | `console` (تطوير فقط) أو `resend` |
| `EMAIL_FROM` | `Al Tareq <hello@example.com>` | بريد المُرسل |
| `PAYMENTS_PROVIDER` | `demo` | `demo` (دفع تجريبي فوري، مرفوض في الإنتاج) أو `paymob` |
| `PAYMOB_SECRET_KEY` / `PAYMOB_PUBLIC_KEY` / `PAYMOB_HMAC_SECRET` / `PAYMOB_INTEGRATION_IDS` | | مفاتيح Paymob من لوحة التحكم |
| `BUNNY_LIBRARY_ID` / `BUNNY_TOKEN_KEY` | | لحماية فيديوهات Bunny Stream |

في الإنتاج يرفض الخادم البدء إذا كان البريد على `console` أو الدفع على `demo` أو مفاتيح Paymob ناقصة أو `BASE_URL` ليس https، ويوضح الخطأ.

## أبرز المزايا

- **للمتعلم:** كتالوج بالبحث والفلاتر، مسارات تعليمية، قائمة مفضلة، سلة تعمل قبل التسجيل، كوبونات، دفع عبر Paymob، مشغّل دروس (YouTube وVimeo وMP4 وBunny Stream المحمي)، تتبع تقدم وسلسلة أيام، ملاحظات لكل درس، اختبار نهائي، شهادات بصفحة تحقق عامة، وسجل طلبات وإيصالات.
- **للمدرس:** استوديو لبناء الدورات والأقسام والدروس والاختبارات مع فحوصات نشر، وسجل أرباح (70% للمدرس افتراضيًا)، وطلبات سحب عبر تحويل بنكي أو InstaPay أو محفظة.
- **للأدمن:** نظرة عامة بالإيرادات الشهرية، إدارة المستخدمين والأدوار، مراجعة الدورات، الطلبات والاسترداد، الكوبونات، الموافقة على السحوبات، وطلبات التدريس.
- **نور، المرشد الذكي:** دردشة مساعدة في كل درس تجيب من محتوى الدورة فقط وتذكر الدرس المصدر، وترد بالإنجليزية أو بالعامية المصرية، مع حدود تكلفة ولوحة تحكم للأدمن.
- **تقنيًا:** تفعيل البريد وإعادة تعيين كلمة المرور، بريد عبر console أو Resend، webhooks من Paymob بلا تكرار، وسوم meta وOpen Graph وJSON-LD من الخادم، `sitemap.xml` و`robots.txt`، `/healthz`، سجلات JSON منظمة، CSP وCSRF وفحص Origin، تحديد معدل الطلبات، ونسخ احتياطية مجدولة.

## الدفع عبر Paymob

تستخدم المنصة تدفق Paymob الحالي (Intention API + Unified Checkout): إنشاء نية دفع بالمبلغ بالقروش، تحويل المتعلم لصفحة الدفع الموحدة، ثم استقبال callback موقّع بـ HMAC-SHA512 يُتحقق منه قبل تفعيل الاشتراك وإرسال الإيصال.

## بناء الديمو الثابت

```bash
npm run build:demo    # يبني نسخة تعمل بالكامل في المتصفح (SQLite على WebAssembly) في dist/
```

الديمو يشغّل كود الخادم الحقيقي داخل المتصفح، وتبقى البيانات على جهاز الزائر. اضبط `DEMO_URL` على رابط الاستضافة قبل النشر (مثل Firebase Hosting — عدّل اسم الموقع في `firebase.json`).
